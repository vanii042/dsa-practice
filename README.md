# DSA Practice in Python

A GitHub-ready collection of standalone Python solutions for common Data Structures and Algorithms practice problems.

## Topics
- Arrays, strings and hashing
- Two pointers and sliding window
- Binary search and sorting
- Linked lists, stacks and queues
- Recursion and backtracking
- Trees and graphs
- Dynamic programming and greedy algorithms
- Bit manipulation, heaps, intervals, tries and union-find

## Run a program
1. Install Python 3.10 or newer.
2. Extract this ZIP or clone the repository.
3. Open a terminal in the repository folder.
4. Run an individual file, for example:

   ```bash
   python 01-Arrays/two_sum.py
   ```

Each file is independent and includes a small example. Most define a function or class that you can reuse in your own tests.

## Suggested order
Start with Arrays and Strings, then Hashing, Two Pointers, Binary Search, Sorting, Linked Lists, Stacks/Queues, Recursion, Trees, Graphs, and finally Dynamic Programming and advanced topics.

## Practice advice
Try solving the problem yourself before reading the implementation. Test edge cases and write down time and space complexity as you go.

These examples are for learning and practice; feel free to modify them.
